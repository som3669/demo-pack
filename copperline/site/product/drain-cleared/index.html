Description

We clear the drain with a cable and water, check the trap and the vent, and run it hot to make sure it stays clear.

What's in the visit

  • Trap removed and cleaned
  • Line cleared with a cable
  • Vent checked
  • Run hot and checked
  • Advice on keeping it clear
Before we come

Clear a path to where we'll work and keep pets in another room. Someone over 18 needs to be home.

If we find a fault

We show you, give you a fixed price, and only fix it if you say yes. Most repairs are done on the same visit.
