# Luma demo pack — credits

All product, store and ingredient-brand names in this pack are invented. No third-party trademark
is used, and no photograph shows a brand name, a logo, readable packaging text or an identifiable
face. The pack is demo content for the Luma theme.

Every photograph is **CC0 1.0**: dedicated to the public domain, free to use, change and
redistribute, including commercially, with no attribution required. Credit is given as a courtesy.
Each file was cropped and recompressed for the pack; `images/sources.json` keeps the source page
and the exact file each one came from. Rawpixel photos are the 1024 px files Openverse links to:
the larger Rawpixel sizes carry a watermark.
